# artlands.github.io

Personal academic site of Jie Li, built with Jekyll on the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT, see `LICENSE`).

- `_pages/`, `_projects/`, `_news/`, `_data/`, `_bibliography/` hold the content.
- `slides/` is the passcode-protected lecture slide site, generated from the private `courses/` folder (git-ignored).

Local preview: `docker compose up`, or `bundle exec jekyll serve`.
